# NGO Program Monitoring & Impact Analytics Report

## 1. Introduction

This project analyzes beneficiary and program data to support monitoring, reporting, and decision-making in organizations.

## 2. Dataset

The dataset contains information about:

- Beneficiary ID
- Name
- Gender
- Age
- District
- Program
- Registration Date
- Attendance Rate
- Amount Received

## 3. Data Analysis

Python was used to analyze:

- Number of beneficiaries
- Beneficiary distribution by district
- Beneficiary distribution by program
- Beneficiary distribution by gender
- Average age
- Average attendance rate
- Amount received by program
- Amount received by district

## 4. Data Visualization

Charts were generated using Python and stored in the reports folder.

The visualizations include:

- Beneficiaries by Program
- Amount Received by Program
- Average Attendance by Program
- Beneficiaries by District
- Beneficiaries by Gender
- Average Attendance by District

## 5. Power BI Dashboard

Power BI was used to create an interactive dashboard containing:

- Total Beneficiaries
- Total Amount Received
- Average Age
- Average Attendance Rate
- Program analysis
- District analysis
- Gender analysis
- Interactive filters

## 6. Conclusion

The project demonstrates how raw organizational data can be cleaned, analyzed, visualized, and presented through an interactive dashboard to support data-driven decision-making.
