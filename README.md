# NGO Program Monitoring & Impact Analytics
> A data analytics project that transforms beneficiary and program data into actionable insights using Python and Power BI.

## Project Overview

This project is a data analytics system designed to help organizations monitor beneficiaries, programs, funding, attendance, and program performance.

The project uses Python, Power BI, and data analysis techniques to transform raw beneficiary data into useful insights and an interactive dashboard.

## Objectives

- Analyze beneficiary information
- Monitor program participation
- Analyze funds received by programs and districts
- Monitor attendance rates
- Create interactive dashboards
- Support data-driven decision making
## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Power BI
- CSV
- VS Code
## Dataset

The project uses beneficiary data containing:

- Beneficiary ID
- Name
- Gender
- Age
- District
- Program
- Registration Date
- Attendance Rate
- Amount Received

The dataset was cleaned and prepared before analysis.
## Dashboard

The Power BI dashboard provides:

- Total number of beneficiaries
- Total amount received
- Average beneficiary age
- Average attendance rate
- Amount received by program
- Amount received by district
- Beneficiaries by program
- Beneficiaries by gender
- Interactive filters for district, program, gender, and registration date
